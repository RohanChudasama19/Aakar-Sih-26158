# SCIENTIFIC CLAIMS & LIMITATIONS

1. **Point Density**: Measured via spherical volume, NOT strict surface density.
2. **Surface Support**: Indicates internal model consistency (cloud-to-mesh), NOT absolute accuracy.
3. **Potential Visibility**: Represents unoccluded camera projections.
4. **Reconstruction Risk**: An uncalibrated diagnostic heuristic. Missing data defaults to UNKNOWN.
5. **Absolute Accuracy**: NOT VERIFIED without external RTK/PPK or ground control points.
